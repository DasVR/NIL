# Batch 2 Inspiration Scoring — AAA Dark Terminal macOS-Native App

## Scoring Key (1-10)
- **DTQ**: Dark Theme Quality — depth, contrast, absence of eye strain
- **TYR**: Typography/Readability — font choices, hierarchy, spacing
- **MNF**: macOS Native Feel — would this feel at home in a Mac app?
- **TAE**: Terminal Aesthetic — monospace vibes, command-line energy
- **UIP**: UI Polish/Refinement — micro-interactions, borders, shadows
- **CLP**: Color Palette — coherence, restraint, accent usage
- **LD**: Layout Density — information architecture, spacing, breathing room
- **TTL**: Total score (out of 70)

## Key Themes for Our Terminal App

### Dark Theme
- **pryzm** shows pure black + glassmorphism is visually striking
- **brittanychiang** shows deep navy is more readable for long sessions
- → Consider: very dark charcoal/navy base rather than pure black for reduced eye strain

### Typography
- **rauno** and **brittanychiang** both show confidence in large type with tight leading
- Terminal apps need monospace, but headers can use system sans-serif (SF Pro)
- → Use SF Pro / Inter for UI chrome, monospace for terminal content

### Layout
- **brittanychiang**'s two-column sticky sidebar is essentially a terminal sidebar + main pane
- **v0**'s large input area = command line input
- → Sidebar (file tree/settings) + main terminal area is proven pattern

### Color Accents
- **brittanychiang**'s green tags = syntax highlighting palette
- **unicorn**'s glow effects = active state / cursor highlights
- → Restrained accent palette: 1 primary (cyan/green), 1 secondary (magenta/purple), semantic colors for errors/warnings

### Polish
- **pryzm** blur/glass effects on overlays
- **unicorn** subtle section borders
- **brittanychiang** consistent spacing rhythm
- → Subtle borders (#ffffff08) for separation without heavy chrome
