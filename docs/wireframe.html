11 · The rebuild itself

before code moves

What "wipe and revamp" means in practice

  • finn_pentest/ survives as-is — it's the engine, not the UI, and you want it for your own security work. Everything under frontend/ is what gets rebuilt.
  • On React packages: you don't need to move the whole app to React to get them. Svelte can mount a React component directly — a thin wrapper calls ReactDOM.createRoot() inside a Svelte component's lifecycle, so a specific package (say, a Twitter-ecosystem chart or gesture lib with no Svelte equivalent) runs in its own island while everything else stays Svelte. A full React rewrite is only worth it if most of what you want turns out to live there — tell me which packages specifically and I'll check whether they need the island approach or have a native Svelte equivalent already.
  • New codebase, same stack unless the above changes that — Svelte + the same tool integrations (xterm, Monaco) so the pentest backend doesn't need touching, just a new frontend built to this rev.
  • On sv-agentation: checked the npm registry directly — it's real, MIT-licensed, actively published (v0.4.0 as of this check). It's a dev-mode Svelte inspector: click an element in the running app, it annotates that DOM node and maps it back to the source file, which is genuinely useful context to feed an AI coding session. It's a build-time dev dependency, not something end users of NIL would see — worth adding when we're actually writing the new frontend, not part of the UI itself.
  • Design docs stay loose on purpose. Not a rules file an agent has to obey line-by-line — just enough to keep a session honest about direction. Something like:
# DESIGN.md One rail, not panes. Terminal appears, then leaves. Warm dark, ember only for "this is changing your files." Every action has a one-line "why" under it. When unsure, look more like Claude than like a dashboard.
  • Sequencing: shell + font are locked (sections 1–2). Next up is settings/diffs/pentest-mode screens on desktop; mobile is deliberately parked until you bring reference for it.
